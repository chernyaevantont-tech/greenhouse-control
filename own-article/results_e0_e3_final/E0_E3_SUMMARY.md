# E0–E3 — финальный снимок результатов

Снимок на 2026-06-30. Симулятор `gl_gym/GreenLightTomato-v0`, Ростов-на-Дону.
Все статейные прогоны считались распределённо на server0/server1.

## Конфигурация (E0/E1)
- Локация Ростов-на-Дону; эпизод **60 сут** (конвенция симулятора `season_length=60`),
  старт 01-03. Train = 2018+2019, in-dist test = **2020**, OOD = 2021–2023 (не использованы
  в E3 — это E5).
- EPI = Σ `profit` из gl_gym `GreenhouseReward` (выручка по приросту x[25] − затраты тепло/CO2/эл-во).
- Цены/коридоры — с живого env: fruit 1.6 €/kg, heat 0.09, elec 0.3, co2 0.3 €; dmfm 0.065;
  коридоры CO2∈[300,1600], T∈[15,34], RH∈[50,85].
- EPI(rule-based, 60 сут, чистый) = **+4.65 €/м²**.

## E2 — лестница идентификации
- 42 рецепта (denoise×optimizer×library×degree), шлюзы embeddability+transparency.
- **Замороженный рецепт (предрегистрация): `physics_no_cross / degree 1 / ensemble / none`.**

## Ключевые выводы
1. Лидеры — `rule_based` и `grey_box_mpc` (статистически неразличимы).
2. Предлагаемый `sindy_mpc` положителен (+0.77), интерпретируем, но **отстаёт** и
   **нестабилен по сидам**; плотный grey-box сильнее разреженного ensemble в closed-loop.
3. Экономический оракул +2.70 — осмыслен (был −15 с band-целью), но **не строгий потолок**:
   узкое место — **горизонт MPC, а не точность модели** (рецедирующий MPC на 3 ч близорук
   к многодневной динамике плода).
4. RL непригоден здесь: PPO сильно отрицателен (data-неэффективен), SAC разваливается (NaN).

## Известные ограничения (→ следующие эксперименты)
- **Один сезон/окно** (2020, ранняя весна), 60 сут; сид меняет только train, тест-погода
  фиксирована (отсюда std=0 у rule_based). Сезонное/годовое разнообразие → **E5**.
- 2021–2023 не задействованы (OOD/E5).
- Полные исправления (EPI-цель, экон. оракул, do-mpc tvp фикс, thread-pin) — в
  `article_experiment_utils.py`; детали инфраструктуры — `../REMOTE_RUN.md`.
