# Региональные погодные данные для GreenLightGym (методика)

Документ описывает, как подготовить вход «реальная погода» для симулятора
`gl_gym/GreenLightTomato-v0` для произвольного региона, и фиксирует конкретную
реализацию для **Ростовской области** (Ростов-на-Дону, 47.24 N, 39.71 E,
2018–2023).

---

## 1. Формат, который требует gl_gym

**Путь:** `gl_gym/data/weather/<Локация>/<год>.csv` (имя `<Локация>` — просто имя
папки, нигде отдельно регистрировать не нужно).
**Разрешение:** 5 мин (300 с), полный календарный год (~105 120 строк; високосный —
105 408). `time` — секунды от 1 января 00:00 UTC.

Заголовок (9 столбцов, как в shipped-данных). По имени загрузчик
`gl_gym.environments.utils.load_weather_data` читает **только 6**:

| Столбец CSV | Единицы | Используется |
|---|---|---|
| `time` | с от начала года | да |
| `global radiation` | Вт/м² | да (iGlob) |
| `wind speed` | м/с | да |
| `air temperature` | °C | да (tOut) |
| `sky temperature` | °C | да (tSky) |
| `??` | — | нет (заполняем 0) |
| `CO2 concentration` | ppm | нет (в модели зашито 400 ppm) |
| `day number` | 0…364 | нет |
| `RH` | % | да (→ давление пара) |

Загрузчик сам досчитывает: давление пара (из T и RH), плотность CO₂ (из 400 ppm),
**температуру почвы** (`soilTempNl`, см. §4), суточную сумму радиации, день/ночь;
затем интерполирует на шаг решателя `h`.

---

## 2. Источник данных

**Open-Meteo Historical (ERA5/ERA5-Land), без ключа.** Endpoint
`https://archive-api.open-meteo.com/v1/archive`, почасовые переменные:
`temperature_2m, relative_humidity_2m, dew_point_2m, wind_speed_10m,
shortwave_radiation, cloud_cover` (`wind_speed_unit=ms`, `timezone=UTC`).
Почасовые данные ресемплируются на 5-мин сетку линейной интерполяцией; радиация
< 1e-10 обнуляется.

Скрипт-генератор погодных CSV: `make_rostov_weather.py` (в scratchpad сессии).

---

## 3. Температура неба (вывод, не измерение)

Open-Meteo не отдаёт нисходящую длинноволновую радиацию, поэтому `sky temperature`
**выводится** из температуры воздуха, давления пара и облачности:

```
e_a      = 6.112 * exp(17.62 * Td / (243.12 + Td))          # давление пара, гПа (Magnus, Td=точка росы)
eps_clear = clip(0.605 + 0.048 * sqrt(e_a), 0, 1)            # ясное небо (Brunt)
eps_sky   = (1 - CC) * eps_clear + CC * 1.0                  # CC = доля облачности [0,1]
T_sky[K]  = eps_sky**0.25 * T_air[K]
```

Облачность линейно повышает эмиссию неба к 1 (облачное небо ≈ чёрное тело при
температуре воздуха).

## 4. Температура почвы для региона — основная методика

### Что делает gl_gym
`soilTempNl(time)` — годовая синусоида **формы Кусуды–Аченбаха** на глубине ~1 м,
подогнанная под нидерландский луг (Jacobs et al., 2011):
`T = 10 + 5*sin(2π(t + 0.625·год)/год)` [°C]. Используется как внешняя граница
`d.tSoOut` под нижним слоем почвы. Для другого климата это неверно.

### Методика (воспроизводима для ЛЮБОГО региона)
1. **Скачать** из ERA5-Land (Open-Meteo archive) почасовую температуру почвы за
   несколько лет (≥3) для координат региона. Слой `soil_temperature_28_to_100cm`
   (узел ~0.72 м) — ближайший к номинальному 1 м; для более глубокой границы есть
   `soil_temperature_100_to_255cm` (узел ~1.89 м).
   ⚠️ Имя `soil_temperature_54cm` для ERA5-архива пустое (это переменная прогнозных
   моделей) — использовать диапазонные имена слоёв.
2. **Подогнать** одногармоническую годовую синусоиду методом наименьших квадратов:
   `T(t) = c0 + c1·sin(ωt) + c2·cos(ωt)`, `ω = 2π/P`, `P = 365.25·86400 с`,
   `t` — секунды от начала года (все годы накладываются по дню года).
3. **Привести** к форме `soilTempNl`:
   `T = c0 + A·sin(2π(t + shift)/P)`, где `A = √(c1²+c2²)`,
   `shift = atan2(c2, c1)/ω`.
4. **Подменить** `gl_gym.environments.utils.soilTempNl` на полученную функцию
   (монкипатч до создания env, т.к. погода кэшируется по `(location, year,
   start_day)`).

### Результат для Ростова (ERA5-Land 0.28–1.0 м, 2018–2023)
| Параметр | Ростов | NL baseline |
|---|---|---|
| T_mean | **11.26 °C** | 10.0 °C |
| амплитуда | **10.36 °C** | 5.0 °C |
| сдвиг фазы | 234.6 сут | — |
| RMSE подгонки (vs почасовой ERA5-Land) | 1.37 °C | — |
| годовой min / max | 0.9 °C (~день 39) / 21.6 °C (~день 222) | ~5 / ~15 °C |

Континентальный климат → ~вдвое бóльшая годовая амплитуда. Глубже (1.0–2.55 м):
T_mean 11.20, амплитуда 7.11, RMSE 0.56 °C.

Итоговая функция:
```
soilTempRostov(t) = 11.26 + 10.356 * sin(2π·(t + 20266007) / (365.25·86400))
```
Реализация: `own-article/rostov_soil.py` (`soilTempRostov`, `apply_rostov_soil()`).

### Чувствительность
Замена NL→Rostov сдвигает внутреннюю температуру воздуха на **~0.30 °C RMSE
(макс 0.59 °C)** (замкнутый env, Ростов-2020, фиксированное действие). Возмущение
±10 °C даёт ~0.88 °C RMSE. Эффект второго порядка, но систематический → коррекция
оправдана, особенно зимой (доминирует обогрев).

## 5. Внешний CO₂
В gl_gym концентрация внешнего CO₂ **зашита = 400 ppm** (столбец CSV
игнорируется). Реальные данные не используются — указать как ограничение модели.

---

## 6. Валидация (сквозь `load_weather_data`, Ростов-2020, start_day=59, 60 дней)
10-мерный вектор возмущений `d` корректен и конечен: iGlob 0–856 Вт/м²,
tOut −4.5…20.3 °C, ветер 0.1–11 м/с, tSky холоднее воздуха, `tSoOut` после патча
1.5→9.3 °C (vs NL 5.1→8.5 °C).

## 7. Воспроизведение
```python
# 1) сгенерировать погодные CSV (один раз)
python make_rostov_weather.py     # пишет gl_gym/data/weather/Rostov-on-Don/2018..2023.csv

# 2) в ноутбуках — до создания env:
from rostov_soil import apply_rostov_soil
apply_rostov_soil()
cfg = ExperimentConfig(location="Rostov-on-Don", growth_year=2020, start_date="2020-02-28")
```
Если ноутбуки запускаются в другом venv — скопировать папку
`data/weather/Rostov-on-Don/` в `gl_gym` того окружения.

## 8. Ограничения (для раздела Limitations статьи)
- Температура неба и давление пара — **выведены** эмпирически (Брунт + облачность),
  не измерены.
- Внешний CO₂ фиксирован 400 ppm.
- ERA5-Land имеет известные смещения температуры почвы в отдельных регионах
  (Cao et al., 2020); для умеренного Ростова некритично.
- Реанализ ≠ локальные станции; для верификации можно сверить с наблюдениями
  Росгидромета (ВНИИГМИ-МЦД, станция Ростов-на-Дону, глубины 0.2/0.4/0.8/1.6/3.2 м).
